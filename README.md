One original fortune-cookie line for a software developer: the code you write today will meet you again in six months — wearing the comments you forgot to write.

## The fortune

> Your code will meet you again in six months, wearing the comments you forgot to write.

Eighty-six characters. A prediction, as a fortune should be: the code you ship today has a life of its own, and when future-you meets it again, it will be dressed in exactly the comments you did not bother to write.

## Run it

```sh
node main.ts
```

It writes the fortune to `/output/entry.txt` (1–120 characters, as the gate requires).
